# GSTR-1 Review Pack - Reproducibility Instructions

This directory contains the necessary artifacts to review the GSTR-1 draft payload generated by MediFlow.

## Prerequisites

If you want to re-generate the JSON locally, ensure you have the backend environment set up:
```bash
cd apps/backend
source ../../venv/bin/activate
```

## Steps to Reproduce

**1. Reset and Seed the Database:**
The JSON is based on dynamically seeded data representing a realistic operating month (simulating the past 90 days). To guarantee a fresh test environment:
```bash
# Set environment variables for the development database
export DATABASE_URL=postgres://mediflow:mediflow@localhost:5432/mediflow
export DJANGO_SETTINGS_MODULE=mediflow.settings.test
export PYTHONPATH=.

# Re-run migrations to ensure schema alignment
python manage.py migrate

# Seed the database
# WARNING: This will drop tables in the test database schema and re-populate them!
python manage.py seed_local_gst_test_data
```

**2. Generate the Draft JSON:**
A Python script is provided to instantiate the `GSTExportService`, generate the data, and dump it into this folder.
```bash
python generate_ca_review_json.py
```

## Payload Details
* **File:** `gstr1_082026_draft.json`
* **GSTIN:** `27AAPCM1753L2ZX` (or the default generated GSTIN from the seeder)
* **Period:** `082026`
* **Contents:** The file includes the standard GSTR-1 outwards supplies arrays (`b2b`, `b2cs`, `cdnr`, `cdnur`) along with a custom MediFlow `_metadata` payload containing pre-flight validation status.
